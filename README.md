## 🎮 Overview

Sims 4 Mod Manager gives you a clean interface to browse, toggle, and organize your Mods and Tray folders, with conflict detection and update notifications.

Whether you're a newcomer or a veteran, Sims 4 Mod Manager provides the tools you need to get the most out of your gaming mods experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Mod Toggle** | Enable or disable any mod with one click without deleting files |
| **Conflict Detector** | Flags mods that share overridden resources |
| **Update Checker** | Notifies you when installed mods have newer versions |
| **Folder Organizer** | Create categories and move mods into logical groups |
